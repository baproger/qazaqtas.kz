# QAZAQ TAS ERP / CRM

Внутренняя ERP/CRM производства **малых архитектурных форм и тротуарной плитки
из мраморного композита**: заявки и КП, сделки, цех, склад сырья, финансы,
зарплата, аналитика, чат и ТВ-экраны на производстве.

В одном приложении — **ERP для сотрудников** (`/login`) и **публичный сайт
с интернет-магазином** (`/`): каталог, 3D-конфигуратор двора, корзина,
оформление и заказ в WhatsApp. Каталог и заказы живут в ERP — второй базы нет.

Стек: **Laravel 13 + Inertia.js + Vue 3 + Tailwind + MySQL**, на витрине —
Three.js, GSAP ScrollTrigger и Lenis. Локализация ru/kk,
таймзона Asia/Almaty. Полное описание модулей и бизнес-логики — в
[PROJECT.md](PROJECT.md), деплой — в [DEPLOY.md](DEPLOY.md).

## Быстрый старт

```bash
php composer.phar install          # или composer install
cp .env.example .env               # заполнить доступы к БД
php artisan key:generate
php artisan migrate --seed         # схема + стартовые данные
npm install && npm run build
php artisan serve                  # http://localhost:8000
```

Первый вход: `admin@qazaqtas.kz` / `password` — **сменить пароль сразу после входа.**

Для локальной разработки можно взять SQLite: `touch database/database.sqlite` и
`DB_CONNECTION=sqlite`, `DB_DATABASE=/абсолютный/путь/database/database.sqlite`.

## Что ставится из коробки

- **Фирма** QAZAQ TAS (код `QT`, номера сделок `QT-001`); система остаётся
  мультикомпанийной — вторая фирма добавляется без изменений в коде.
- **Воронка сделки:** Заявка → Замер и расчёт (гейт технолога) → Договор →
  Закуп сырья (гейт снабженца) → Логистика → Монтаж → Акт → ЭСФ → Оплата успешно.
- **Три производства:** Шымкент, Алматы, Тараз. У каждого своя воронка цеха
  (Формовка → Шлифовка → Упаковка → Отправка), свой ТВ-экран и свой доступ
  сотрудников; при отправке сделки в цех выбирается город.
- **Каталог витрины:** 6 категорий и 16 позиций (плитка, бордюры, вазоны,
  скамьи, урны, ступени) с характеристиками, палитрой и ценами.
- **Склад:** 18 позиций сырья и расходников (мраморная крошка, цемент, смола,
  пигменты, формы, паллеты…), **категории расходов**, **отделы**, доп-поля сделки
  (тип изделия, цвет/пигмент, фактура).

Всё это правится в интерфейсе: Настройки → Этапы / Доп. поля / Экраны, «⚙ Категории»
на Финансах, «⚙ Чек-лист» на Заявках.

## Разработка

```bash
composer dev          # сервер + очередь + логи + vite одной командой
php artisan test      # 280 тестов, гонять перед каждым push
npm run build         # public/build закоммичен — собрать перед push
php artisan schedule:work   # просрочки, дни рождения, сроки КП
```

## Полезные команды

| Команда | Что делает |
|---|---|
| `php artisan migrate:fresh --seed` | пересоздать базу со стартовыми данными |
| `php artisan tasks:notify-overdue` | уведомления о просроченных задачах |
| `php artisan users:notify-birthdays` | дни рождения сотрудников |
| `php artisan pre-deals:notify-quote-deadline` | напоминание об истекающем сроке КП |
| `php artisan optimize` | кэш конфигов/роутов/вью (обязательно после деплоя) |

## Безопасность

`.env`, ключи и реальные данные в репозиторий не попадают. На проде:
`APP_DEBUG=false`, `SESSION_SECURE_COOKIE=true`, HTTPS принудительно, включён
OPcache. Все действия пишутся в аудит-лог.
